# Human-reference pilot: preregistered protocol
Six configurations: gpt-5.6-terra medium/high; gpt-5.6-sol low/medium; gpt-6-astra low/medium. Four passages each, 24 fresh isolated translation sessions, identical instructions. One run per cell; no retries for weak translations. Fresh sessions receive only their Kyrgyz passage and instructions, without English, other candidates, dictionaries or web access. Tool restrictions are instructed, not OS-enforced. Record observed compliance and missing runs.

Source: Karalaev, Manas (2010), original PDF SHA256 53bb71b63a0ad255e815b57f23fb41c8f3160cf05fd7b374add3516c7ccd99d7. Selected extraction visually checked on PDF pages 17,87,129,130,150. Human reference: Elmira Köçümkulkızı’s attributed Karalaev translation, reviewed with Daniel Waugh; introduction http://www.silkroadfoundation.org/folklore/manas/manasintro.html. Published human reference is withheld from translators. Human English is retained locally only, not republished in this repository.

IMPORTANT: human English is based on 1995; our Kyrgyz is 2010. These are manually aligned passage-level parallels, NOT verified identical editions. Evaluate shared meaning units only. Exclude disputed typography, geographic detail in passage 2, imperative versus past tense in passage 3, and uncertain weapon modifiers in passage 4. Do not penalize source-correct alternatives merely for differing from the reference. Document further edition ambiguity rather than force judgment.

Primary endpoint: 12 prespecified shared meaning units per passage, each scored 0 absent/wrong, 1 partial or materially weakened, 2 preserved. Equal passage weights, maximum 96. Grade neighboring lines together to permit syntax crossing line boundaries. Record errors with candidate line numbers. Missing source lines and nulls reported separately; completeness is not inferred from fluency. No lexical-overlap score because valid poetic wording varies.

Randomize candidate IDs independently per passage; hold model key unread until grading is fixed. Use two independent reference-grounded blinded assessments where practical; report disagreements and their effect on ordering. These are AI judgments against an attributable human anchor, NOT independent human evaluation. Human reference itself can err. Do not treat Astra as ground truth.

Four purposively selected short passages from early Manas are a pilot, not a random sample of the 500,553-line cycle. One run per cell cannot measure within-prompt stochastic variance. Public text may have been seen in training, so memorization cannot be excluded. No statistical significance or whole-poem accuracy claim. Report tool-observed run durations only if recorded; no token/cost claim without actual usage data.
